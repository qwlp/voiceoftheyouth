# Voice Of the Youth

A responsive, buildless static website using HTML, CSS, and JavaScript, published with GitHub Pages from the `main` branch. Fonts, icons, photos, and the homepage video are served locally.

## Preview

Run `python -m http.server 8000` and open http://localhost:8000.

## Pages

The homepage is `index.html`. About, team, history, get-involved, tutoring, upcoming programs, volunteer recruitment, sponsorship, partner, and merchandise pages are separate root-level HTML files. Shared styling and behavior are in `styles.css` and `script.js`.

See `CONTENT-AUDIT.md` for the original content sources and local page mapping. Google Forms continue to handle registration and ordering. Google Drive continues to host instructor biography documents and two embedded videos from the source pages.

## Publish

Push to `main`. GitHub Pages deploys from the repository root; no dependencies or build step are required.
