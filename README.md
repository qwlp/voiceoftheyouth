# Voice Of the Youth

A responsive, buildless website using HTML, CSS, and JavaScript. Original branding, photos, and video are included locally in `assets/`.

## Preview

Run `python -m http.server 8000` in this directory and open http://localhost:8000.

## GitHub Pages

GitHub Pages publishes directly from the `main` branch, using the repository root. Push changes to `main` to update the website. No packages or build step are required.

Program links open email inquiries; the original material does not include current registration dates or forms. Update the email addresses, social links, and program details as needed in `index.html`.
